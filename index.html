在机器人上安装

这是 Wireless Linux Python 应用。使用 Reachy Mini Dashboard 安装本 Space，然后在 Home Assistant 中添加自动发现的 ESPHome 设备。

系统需具备 PulseAudio/PipeWire 与 libmpv。安装步骤、配置和测试范围请阅读说明。
